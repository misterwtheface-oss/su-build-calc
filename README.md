# Siralim Ultimate — Build Calculator

A theorycraft sandbox for [Siralim Ultimate](https://store.steampowered.com/app/1289810/):
plan a party of 6 creatures, fuse them, build their artifacts and relics, socket your
Nether Stones, and toggle your realm cards — all against a faithful reproduction of the
game's math, so you can test builds without grinding them in-game.

Vanilla HTML/CSS/JS, no framework, no build server. Deployable as static files.

## Features (P0)
- **6 creature slots + a Specialization slot** — build-first home screen, everything opens in overlays.
- **1447 creatures** with real battle sprites, class/race, code-authoritative base stats.
- **Fusion** — pick a secondary parent; the offspring gets the *average* of both parents' base stats,
  the *secondary* parent's class, and *both* traits (codex-accurate).
- **Artifacts as containers** — an overlay builds each artifact: 1 primary stat + properties
  (25 stat / 47 trick) + trait-item slots + Nether sockets, at any rank 1–50.
- **Relics** — 31 god relics with per-rank effects.
- **Nether Stones** — enter the stones you actually rolled in-game (name, rarity, properties);
  they're saved in your browser and socketable into any artifact.
- **Realm Cards** — 141 families; default all owned & on, toggle to match your collection.
- Party persists in `localStorage` (`subc.*`). Scroll never resets; overlays are statically sized; mobile-first.

## Run locally
```
node build-data.mjs         # regenerate data.js + copy used sprites (needs ../_su_extract)
node tools/serve.mjs        # preview at http://localhost:5173
```
`data.js` is committed, so for a pure preview you only need `serve.mjs` (or open `index.html`).

## Data
All data is generated by `build-data.mjs` from the sibling `_su_extract` datamine workspace
(code-grounded; **not** shipped in this repo). See `WIKI_CONTEXT.md` for the pipeline and
`SPEC_PLAN.md` for the architecture and roadmap. `Progress.md` is the cross-session log.

## Deploy (later)
Static — push to GitHub and enable Pages on `main`/root. No build action needed.
The Cloudflare analytics beacon in `index.html` ships commented out; enable it only at public release.
